# 2026-09-13 workflow rule migration map

Task `wf-task-lifecycle` consolidated operational duplication around the task
lifecycle without changing any safety or product rule. This map records, for
every existing rule the task touched or relied on, where it now lives and why.
It is historical evidence under the Constitution's section 20; it creates no new
normative rule.
