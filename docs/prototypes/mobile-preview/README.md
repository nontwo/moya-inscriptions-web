# 交互原型（手机 / 平板 / PC 自动识别）

> **非生产原型（prototype shell only）：**
> 本目录用于验证信息架构、导航、交互手感与设备响应式呈现；不是正式 Web /
> T06–T08 验收交付，也不连接 Repository、数据库、Reader/API 或 SearchDocument。

Synthetic T02 是正式产品的行为、交互与压力测试参考；`dataset=p5`
的28条内容模式是已批准的真实中文标题、可选字段与内容密度参考。两者都是可演进的Product
Contract参考，不是第二套应用或runtime事实来源。正式`apps/web`是唯一逐项把DEMO能力替换为REAL能力的产品。

同一 URL 复用一套 DOM 和交互状态。`device-platform.js`
在样式加载前结合 UA、视口宽度与方向设置：

- `data-device-class="phone|tablet|desktop"`：物理设备类型。
- `data-platform="phone|tablet|pc"`：当前实际启用的壳层。

原型保留首页“发现/附近/专题”、碑刻搜索与详情、书帖分类和本地筛选、设置页、主题循环按钮（浅色 / 深色 / 跟随系统）、手机与平板首页单双列循环按钮、`localStorage`、history 返回和滚动位置恢复。「专题」仍是策展占位，不是社区帖或 CMS。手机与平板共用一份
`data-home-layout`（`single` /
`double`）：单列始终 1 列、双列始终 2 列。首页（发现 / 附近 / 专题）和书帖（全部 / 墨迹 / 拓本）按最短列瀑布流参差排布；碑刻列表不读取这份布局状态，始终是独立的全宽横长卡片（左图右文、等高），不进入瀑布流，也不随单双列按钮变成两列。切换栏目、分类、页面或横竖屏后会重新计算列宽，不因页面重挂载而重置。PC 忽略这份布局状态：首页 / 书帖仍按内容区宽度做 3–8 列自适应瀑布流（列宽约 220–320px），碑刻仍是一条全宽横卡。首页发现 / 附近 / 专题与书帖共用同一套内容卡片：宽度和圆角统一，高度跟随图片真实比例，由现有 Masonry 按最短列补位；不裁切图片，也不再使用固定行高网格。碑刻是横长方型卡片，标题横向排版，不使用竖排。碑刻卡片高度统一，图片在固定区域内
`cover`，不因原图比例撑高卡片。

## 设备判定

| 设备类型                         | 视口        | 壳层                      |
| -------------------------------- | ----------- | ------------------------- |
| 手机 UA / `userAgentData.mobile` | 任意        | 手机；不会升级到平板或 PC |
| 平板 UA / iPadOS 触控 Mac UA     | `<768px`    | 手机降级壳                |
| 平板 UA / iPadOS 触控 Mac UA     | `≥768px`    | 平板；不会升级到 PC       |
| 桌面 UA                          | `<768px`    | 手机                      |
| 桌面 UA                          | `768–895px` | 平板                      |
| 桌面 UA                          | `≥896px`    | PC                        |

物理手机、平板和 PC 三端首页/碑刻/书帖均使用底部浮动液态玻璃胶囊；内容从玻璃下方连续透出，导航不参与页面高度、也不在胶囊下方再垫一整条背景。手机和平板主视图底部不留可见占位，只在内容滚动容器内保留不可见的
`--app-bottom-nav-clearance`，让最后一张卡片能滚到胶囊上方。底部「首页 / 碑刻 / 书帖」与页面横向切换共用同一进度：拖动底栏气泡、内容左右滑（碑刻页）或鼠标按住拖动都会让页面和气泡同步跟手，松手后按距离和速度弹簧完成或回弹。顶部「发现 / 附近 / 专题」和书帖分类保持普通 Tab（选中色 + 下划线），不做气泡化。首页栏目和书帖分类仍可在各自页面内左右滑（手机/平板触摸；PC 用横向滚轮），不会在滑到边缘后切入主导航。PC 底栏支持 hover、点击动画和鼠标拖动，不把气泡瞬移到目标栏。`prefers-reduced-motion`
时底栏只响应点击。上下滑动内容时底栏收成约 44px 小圆，圆内只显示当前栏目的印章红图标、没有文字；向下滚动超过阈值才收缩，向上超过更大阈值才展开，避免来回抖动。收缩约 420ms、恢复约 520ms，滚动停止约 400ms 后也会展开，点圆也可展开。小圆内图标由独立 wrapper 水平垂直居中。首页和书帖卡片按图片比例参差排列；碑刻列表始终是等高横长卡片。手机/平板碑刻只由列表主滚动容器承担纵向滚动，PC 碑刻与首页/书帖一样走 document 滚动。首页 / 碑刻 / 书帖列表在打开详情、设置时保持挂载，由覆盖层盖住而不是
`display: none` 卸掉，避免返回后图片和卡片空白。三端静止时主分页轨道不挂
`transform`，只在跟手拖动或弹簧结算期间平移，避免 PC 滑动闪烁和手机切到书帖后整页空白。PC 首页栏目和书帖分类在跟手结束后同样卸掉轨道
`transform`、只保留当前页，避免内容被移出视口后只剩顶栏和底栏。PC 触控板只有明确横向位移才会跟手切页，纵向或斜向滚动不展开相邻页；跟手期间锁定主壳高度，滚动和图片加载引起的高度变化不会重对齐分页或重建瀑布流。手机和平板的纵向滚动只发生在各页自己的 overflow 容器里，分页手势在锁定为横向之前使用 passive 监听，不拦截原生惯性；底部液态玻璃导航相对可视视口 fixed，不跟内容一起滚出屏幕。列表卡片只显示标题与元信息；简介和说明都在详情页标题面板之外的阅读区，不再进入标题容器。书帖瀑布流在页面宽度就绪前保持隐藏，避免首次进入时卡片被压成左侧细条后再跳回正常布局。分页轨道只在拖动或弹簧结算时使用
`will-change`。1024px、1440px 只加宽边距。底栏气泡用 `transform`
连续移动，不把气泡重新插入按钮。横向滑动不触发浏览器前进后退。布局与 document 滚动不变。PC 首页顶栏不显示加载页格言。PC 底栏 hover 只强调文字，不改变当前选中项。

运行时监听窗口缩放、方向、visual
viewport 与分页容器尺寸变化，在真实宽度稳定后重新对齐分页轨道，并重新计算瀑布流列数、碑刻网格列数与卡片宽度，不刷新页面。三端碑刻 / 书帖 / 首页进入同一套 Catalog
Detail：返回隐藏主导航、保留来源滚动，并在 895 /
896 与方向变化时保持当前条目与选中图像。详情主图放在统一高度的展示区内
`contain`，按自身长宽比适配，不因栏目或构图模式变成过大或过小。多图时右上角页码和底部小点固定叠在展示区上，单图不显示；查看器内页码仍在翻页时显示、停止 2 秒后隐藏。Hero 为主图、图片切换和信息卡片的纵向文档流（身份 / 简介 / 基本资料）；顶部身份行会按字段与「基本资料」去重，只保留资料里没有的类型或别名，避免朝代、年代等重复。说明和资料来源留在主图之后。点击主图打开独立图像查看器；默认按 Viewer 可用区域最大化 contain。详情页与查看器共用同一套跟手轮播：先判断并锁定水平/垂直方向，水平时图片跟手、相邻图同时进入，松手后按距离和速度完成切换或回弹；垂直交给页面滚动。Mac 触控板横向一次手势只切一张，纵向滚动不被图片组件吃掉。查看器内点击图片关闭，不再显示「关闭」按钮。关闭后忽略紧随其后的合成 click，避免查看器闪一下又打开。手机和平板轻点底栏栏目即可切换页面，气泡平滑跟到目标；拖动超过阈值才跟手，避免把点击当成滑动。手机/平板左右滑动翻页，PC 用拖动、左右边缘点击、方向键与触控板横向手势。PC 滚轮（含 Ctrl
/ 鼠标滚轮）只缩放图片。缩放与拖拽只作用于查看器内图片，不缩放网页、也不恢复已移除的「图像」缩略图区。内容卡片、详情主图和查看器图片使用同一套圆角与悬浮层级：列表卡片用
`--app-elevation-content`，详情主图框和资料面板用
`--app-elevation-panel`；查看器阴影写在图片上，随平移、缩放和左右切换一起移动。PC 首页 / 书帖瀑布流把阴影放在图片上（卡片背景透明）；碑刻横卡把阴影放在整张卡片上。悬停只轻微上浮并加强阴影，不放大。设置页用图标循环切换主题与列表列数（PC 不显示列数按钮）；手机与平板的单双列同时作用于首页（发现 / 附近 / 专题）和书帖（全部 / 墨迹 / 拓本），碑刻始终忽略这份设置并保持全宽横卡；横竖屏都读取同一套
`data-home-layout`，调试日志会记下设备、方向、页面、栏目和列数。「查看调试日志」可在手机/平板查看导航、详情、切图和主题等 QA 记录（`#settings-log`），设置页和日志页都可一键复制本次记录，不是生产分析。

## 样式隔离

- `preview.shared.css`：三端一致的结构、圆角内容卡片、统一悬浮阴影、专题、表单与加载样式。
- `preview.css`：手机触摸分页、横竖屏内容密度及始终位于底部的液态玻璃底栏覆盖。
- `preview.tablet.css`：平板触摸分页、专题边距，以及横竖屏均回到底部浮动胶囊的覆盖。
- `preview.pc.css`：PC 滚动、底部液态玻璃导航、主导航跟手分页、多列瀑布流边距、碑刻全宽横卡、卡片悬停与触控板分页覆盖。

共享样式始终加载；三个平台覆盖表均随页面加载，但任意时刻只启用 `data-platform`
对应的一份，避免宽屏手机或平板被纯媒体查询错误升级。

三个固定导航字标保留原始 PNG 轮廓，并以 CSS
mask 跟随当前按钮颜色，避免浅色或深色主题出现灰色像素。碑刻搜索和书帖筛选的输入框不显示装饰性放大镜；独立搜索操作图标不受影响。手机竖屏书帖将分类与设置置于第一行、筛选框置于第二行。

纵向内容使用浏览器原生滚动，不拦截纵向 `wheel`
或触摸事件；PC 仅在首页栏目和书帖分类上拦截横向触控板 `wheel`
做跟手切页，静止时仍是单页 document 滚动。macOS 触控板惯性和鼠标滚轮的纵向滚动由当前页面的唯一主滚动容器处理。导航 Glass 只用于功能层，内容卡片和碑刻详情仍使用不透明纸墨 Surface。
