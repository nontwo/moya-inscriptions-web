# 交互原型（手机 / 平板 / 桌面）

> **非生产原型：**
> 本目录用于验证信息架构、导航和交互手感，以及平板与桌面的响应式呈现；不是正式 Web 页面，也不能作为生产实现直接发布。

原型完整保留首页“发现/附近”切换、碑刻搜索过滤、书帖分类、详情进入与返回、设置页、明暗主题、单列/双列偏好、`localStorage`
持久化、浏览器 history 返回和滚动位置恢复。

它不连接真实 Repository、数据库、搜索服务或生产图片。页面仅引用
`docs/design-system/assets/demo/`
中的虚构演示图，不在原型目录复制资产；正式应用仍须通过图片适配器从 object
key 派生 URL。

## 响应式结构

| 宽度                    | 结构                                         |
| ----------------------- | -------------------------------------------- |
| `< 768px`               | 手机画布（最大 430px 居中）+ 固定底栏        |
| `768–895px` 竖屏        | 全宽平板布局，保留底栏，加大内容留白与列宽   |
| `768–895px` 横屏        | 同一批主导航改为左侧轨，内容占满剩余宽度     |
| `≥ 896px`               | 侧栏与顶栏控件放大（约 1.25×）；印泥红选中+右三角；A/B/C 三页布局；书帖流式密铺 |
| `≥ 1024px` / `≥ 1440px` | 首页卡片再放大；书帖随视口继续流式列；碑刻行再放大；详情 ≤760px |

手机端信息架构冻结。桌面侧栏 Logo 克制放大；顶栏「发现/附近」、书帖分类与碑刻搜索控件同比变大。

## 本地查看

从仓库根目录运行：

```sh
python -m http.server 4173
```

打开 `http://localhost:4173/docs/prototypes/mobile-preview/`。关联的交互场景位于
`tests/integration/prototypes/mobile-preview.test.ts`。

建议在浏览器开发者工具中检查360 / 390 / 430 / 768 / 834 / 1024 /
1440px，并分别旋转平板竖屏与横屏。
