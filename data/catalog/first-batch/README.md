## PDF 原始字段

PDF 每行只有五列：序号、省份、文物名称、文物保护单位/文物收藏单位、年代。对应字段分别为
`sourceIndex`、`regionRaw`、`nameRaw`、`protectionOrCollectionUnitRaw` 和
`periodRaw`。其中保护/收藏单位是不可拆分的合并字段。

## 提取方法

1. 读取 PDF 内嵌文本和表格线，每页提取唯一表格，不对整份文件重复 OCR。
2. 按列边界读取五个原始字段；单元格内的排版换行直接拼接，不增加或删除字符。
3. 从 PDF 页位置记录真实 `sourcePage`，不按序号估算页码。
4. 校验序号恰好为 1–1658、无重复、无缺号，五个原始字段全部非空。
5. PDF 中序号 1000 只出现一次，没有删除或重编号。
6. 第 1307 条的一个字符在 PDF 中显示为 `?`，按原文保留并标记人工复核。

## 候选市县数据

`region-enrichment.json`
保存从原 PR 和补充工作簿迁移来的现代行政区候选，不属于 PDF 源数据，也没有任何已选定候选：

- 1658 条关联记录、1665 个候选，其中 7 条有两个相互冲突的候选。
- 现有候选中，1649 条至少有 city、1654 条至少有 county、1645 条至少有二者。
- 所有候选均为 `unverified`，全部记录
  `needsReview=true`，逐条证据 URL 数量为 0。
- 4 条候选省级归属与 PDF 的 `regionRaw` 不同，两者分别保存，不覆盖历史源表原文。
- `selectedCandidateIndex` 只有在候选具备逐条证据并完成审核后才能设置。

## 数据限制

PDF 不包含经纬度、书体、作者、详细地址、图片、释文、类别或说明。应用契约允许未来补充这些字段，但当前数据不得推测。地区候选、同名记录和年代标签均需结合独立来源继续审核；本数据集不等同于完整碑刻详情数据库。
