# Repository Development Authority

Before planning or modifying repository files, read
`docs/governance/OWNER-DEVELOPMENT-CONSTITUTION.md`.

The Constitution is the highest repository development authority below an
explicit Owner amendment. No task prompt, Plan, implementation decision, PR
description, inferred best practice, or code comment may relax or override it.

If a task conflicts with the Constitution: STOP and report the conflict. Do not
silently expand scope. Do not modify nested Owner-local instruction files unless
explicitly authorized.
